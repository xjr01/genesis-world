# full3：杯口零碎出液与混合过快

2026-09-23。用户请求修改意见。本轮读取最新full3配置、指标、浓度/渲染代码，并从已有视频提取6个特写帧（10.5/12/16/24/27.2/30s），亲检12/24/27.2s。没有运行新仿真，也没有更改生产脚本、引擎或配方。

## 1. 当前基线与证据

full3：旧settled、B档h=1/480*20轮、area=.0048、density375000、surface/interior XSPH=.2/.05、friction=.1、adhesion=1e12、diffusion=.005。不要沿用full1粘性为零的旧诊断；最新小粘性试验效果有限，.2/.05已经通过起流验证，应先保留。

当前角度：11s到72度后保持至26s；26–27.5s升到86度；30–31s收至65度并退让；34–34.75s再到112度。由full3的粒子计数计算净出缸率：

| 区间 | 净出缸粒数/秒 |
|---|---:|
| 10–12s | 3749.5 |
| 12–16s | 293.25 |
| 16–20s | 104.5 |
| 20–26s | 63.0 |
| 26–30s | 2103.75 |
| 30–34s | 50.25 |
| 34–37s | 1231.33 |

这是区间净流量，不是逐时刻严格单向通量。足以确认时间线有“先较大流量、长时间滴流、再增流、再停、再脉冲”的结构。特写24s能看到细长断续点链；27.2s重新出现较粗入流。

大杯在12s已接收7459粒奶、26s9491粒，逐渐接近满杯。持续大规模咖啡出杯在约26.9s出现（首次>=100粒），28s出杯3593粒、30s4157粒；早先个位/十位出杯计数会回落，因此不能把所有杯沿起伏都称为持续泄漏。外部数量还会受统计容差/回流影响，不能由计数单独证明每粒从哪里越沿。

用户的“杯口”可能指小杯出口或大杯满杯沿，本轮已发出澄清问题；在得到具体定位前，两处分别给建议，不擅自认定需要取消溢出情节。

## 2. 混合：优先改浓度扩散，不改粘性

实际更新为：

    c_i_next = c_i + eps_d * V * sum_j W_ij * (c_j-c_i)

每子步一次，当前每秒480次；eps_d=.005。它是浓度场的人工平滑，没有反馈密度/压力/粘性物性。降低它可以减少直接颜色扩散，不必撤销已有效的速度平滑。

首选候选：.005 -> .0005（10倍减弱）；若仍过快，再.0002（25倍减弱）。单独跑eps=0对照分辨“粒子携带颜色的对流缠绕/点渲染视觉平均”和“浓度数值扩散”。关闭扩散也不会阻止不同颜色粒子在流动中交错，不能承诺永远分层。

regular完整静息邻域的Taylor估计：D_eff=eps_d/(6h)*sum_j(V*W_ij*r_ij²)。ps=.002、R=.006时，sum(VWr²)=8.13354e-6m²；eps=.005对应D_eff约3.2534e-6m²/s，.0005对应3.2534e-7。单轴1s平滑尺度sqrt(2D)约2.55mm和.807mm，说明毫米级细丝可很快模糊。该估计局限于固定规则邻域，不能据此声称全杯在某个确定秒数均匀，也不将人工D解释为真实牛奶分子扩散系数。

已有CSV仅记录sum(c)守恒，不记录局部方差/分布，无法认证“瞬间全杯混匀”。建议增加杯内c直方图、纯奶/纯咖啡比例与条件混合指数M=1-var(c)/(mean(c)*(1-mean(c)))，mean接近0/1时报告NA；同时输出颜色快照，分开看物理输运和显示。

代码注意：`build_scene()`传入的是DIFFUSION_EPS常量，单改RECIPE中的diffusion_coeff不足以确保生效；实施时应统一参数透传、CLI和日志回显。

## 3. 杯口形态：先调连续流量与时间线

若主要指小杯出口滴流：优先将26s才增倾的时机提前到14–16s，或在12–18s将72度平滑增至82–86度；具体角度需要流量短测，不能把粒子计数同比外推。目标是随液位下降继续增倾，避免在72度排液平衡附近挂十余秒，不是再次堆粘性或张力。

若主要指大杯零碎越沿：保留“倒满、约2s鼓包展示、连续溢流”叙事，缩短临界满杯小流量停留，避免再拉长30–34s的收流/再注入。溢流阶段用持续中等入流代替断续小流量；112度排空动作可单独测试延长ramp .75s到1.5–2s，减小突然脉冲。这些候选应按用户希望的镜头时段统一重排，不能分别改常量导致阶段重叠。

第一轮保持装液量不变。若确定是大杯过早进入临界满杯，可再单独试H_COFFEE .090 -> .086m（初始咖啡约少4–5%，实际粒数重新核对），增加缓冲空间但仍保留最终溢出；需要重新采样与settled，不与扩散/时间线同时混改。不能靠把密度压缩回旧PBD水平腾容量。

暂保area=.0048及visc=.2/.05。降低compliance增强张力可能加重局部成珠和穹顶，不是连续溢流的默认解法。若确认是接触层钉扎，可另测杯壁摩擦.1降至.01–.03、桌面保持.1；当前材质摩擦是全局参数，分开设置需要新增逐collider控制，不能直接把全局.1改小而忽略桌面效果。

## 4. 渲染对观感的影响

full3特写使用10像素点粒子，图像直接暴露离散点链和颗粒边沿。连续表面重建可改善表现，但必须先区分物理出液间断与画面离散，不能把重建抹平当作物理修复。

目前颜色映射c=.5为亮黄色(.95,.78,.30)，不是自然浅棕；画面同为金黄不能直接证明c完全均匀。建议在确定扩散后再单独调整奶白—浅棕—深棕显示映射，保持真实浓度不变。

PBSTF当前recon分支逐entity重建；若上线，应先验证将咖啡和奶粒子合并重建同一液面、再插值c着色，避免两套重叠表面产生假界面。此项是显示工程，额外耗时也须计入，不建议在此次首轮物理试验同时启用。

## 5. 推荐验证顺序

1. 保留full3全部动力学，仅diffusion=.0005，验证奶色细丝/涡卷持续时间、浓度守恒和分布；必要时加eps=0诊断短片。
2. 保留选定扩散和原动力学，做连续增倾/缩短滴流停留的时间线对照，记录净出缸/入杯/出杯曲线和杯沿连通流股。
3. 只有仍有明确问题，才分别调整初始余量、杯壁摩擦或area；每次单一因素，检查抖动/穿隧/流量，不回退已验证稳定设置。
