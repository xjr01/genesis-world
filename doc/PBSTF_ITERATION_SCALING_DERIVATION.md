# PBSTF 参数与迭代数、dt 的联合关系

2026-09-22。用户要求的公式分析；不修改引擎或生产参数。适用当前 multiflow PBSTF，不自动适用于有累计lambda的XPBD或IPBF。整场景缩放记号沿用 `PBSTF_UNIFORM_SCALE_DERIVATION.md`。

## 1. 先数清实际执行次数

令N为每子步求解迭代数，K为某一约束在一个子步实际执行次数。当前 `pbstf_solver.py` 调度：

| 算子 | K或调用次数 | N=5到20 |
|---|---:|---:|
| 密度约束 | N | 5到20 |
| 面积约束 | N | 5到20 |
| 壁附着（启用时） | N | 5到20 |
| 表面/内部距离约束 | ceil(N/2)，iteration=0也执行 | 3到10 |
| XSPH | 每子步1次，在位置求解后 | 1到1 |
| 浓度扩散（启用时） | 每子步1次 | 1到1 |
| 壁摩擦 | 最终粘性阶段每个接触collider处理一次 | 不直接依赖N |
| 拓扑与hash重建 | 循环内ceil(N/I)，另有循环外更新 | I=2时3到10 |

每步全局速度保留系数q若由场景额外施加，也要按它实际的执行阶段计数；当前PBSTF不因此自动拥有旧PBD的velocity_damping选项。

## 2. 单个约束的非线性迭代关系

在无其他约束干扰、梯度和有效质量固定、活跃集合固定的局部线性模型下，定义：

    G = m0 * sum_j |grad_j C|^2/m_j
    lambda = -C / (c/m0 + sum_j |grad_j C|^2/m_j)
    delta x_j = lambda * grad_j C/m_j

将delta x代回线性化C，得到一次迭代的残差比例：

    C_after = q*C_before
    q = c/(c+G)
    C_after_K = q^K*C_initial
    total_correction_fraction = 1-q^K

增加迭代，残差按指数下降，总修正逐渐饱和；它并非始终正比于K。保持dt、几何不变，要将K改为K'并保持相同总修正，必须令q'^K'=q^K：

    c' = G / ((1+G/c)^(K/K') - 1)

这是上述单约束线性模型的精确关系。c=0且G>0时一次即完全投影，更多轮不增加该孤立约束修正；公式按极限处理。G=0则该线性化约束没有可修正方向。

若k=K'/K，且G/c很小：

    c' = k*c + (k-1)*G/2 + higher-order terms
    => c' approximately k*c

注意方向：迭代更多，若要保持效果，应提高compliance，让每轮更软；直接除以k会同时提高执行次数与单轮强度。

对k=4，以下为单约束非线性结果：

| G/c | c'/c |
|---:|---:|
| .001 | 4.00150 |
| .01 | 4.01497 |
| .1 | 4.14702 |
| 1 | 5.28521 |
| 10 | 12.17789 |

因此不能仅看c数值是否“大”判断线性比例成立，必须看同量纲的G/c。密度、面积、边界、表面和内部的G各不相同。

## 3. 距离与壁附着可以给更具体的估计

同质量孤立粒子对，距离约束两端单位梯度给G=2。两端受其他约束影响时仍只是局部参考；接触开关变化时不适用固定K残差模型。

N=5到20时K=3到10：

    surface distance c=40 -> 135.6420
    interior distance c=180 -> 602.3277

弱修正按10/3倍给133.333和600，接近但不等于上述结果；乘4得到160/720则连执行次数都没匹配。

孤立固定壁法向附着、粒子质量=m0时G=1；N=5到20，c=20得到c'=81.4848（弱修正80）。这与壁摩擦不同：壁摩擦不在N轮循环中，无需因N改动而跟随调整。

密度、面积的G随局部邻域/网格变化，一个全局c'不能让每个粒子的q'^K'都完全匹配。建议先观测G/c分布，再判断线性倍率是否有依据；不凭当前c的数量级直接下结论。

## 4. 同时改变场景大小

若C为长度p次齐次约束、粒子密度不变，则G'=s^(2p-2)*G。仍保持dt'=tau*dt及完整时间相似变换，得到：

    c' = s^(2p-2)*G / ((1+G/c)^(K/K') - 1)

弱修正简式：

    density c' approximately s^-2 * (N'/N) * c
    area c' approximately s^2 * (N'/N) * c
    distance c' approximately (ceil(N'/2)/ceil(N/2)) * c
    adhesion c' approximately (N'/N) * c

粒子质量仍乘s^3；rho0、表面目标系数.7、support/ps比、分类比例阈值不随N改变。拓扑更新频率是另一变量，不能由compliance吸收。

## 5. dt联合推导：为什么出现平方，而不是每秒投影次数

孤立线性约束可用一个误差坐标e表示，预测后误差为e_pred，K轮结果为：

    e_next = Q*e_pred
    Q = (c/(c+G))^K

同时速度由位置差分回推。对线性振子采用隐式Euler，具有同形映射：

    e_next = e_pred/(1+omega_eff^2*dt^2)

因此在这个模型中：

    omega_eff^2 = ((1+G/c)^K - 1)/dt^2

这是等效线性恢复强度，不是测得的物理表面张力sigma，也不是多约束PBSTF的全局频率。

设长度比s、目标时间比tau、实际子步比eta=dt'/dt。要求omega_eff'^2=omega_eff^2/tau^2，得到联合非线性公式：

    c' = s^(2p-2)*G /
         ( [1+(eta/tau)^2*((1+G/c)^K-1)]^(1/K') - 1 )

当eta=tau，退化到第4节；当K'=K且eta=tau，退化到上一份文档的严格齐次公式c'=s^(2p-2)c。

只有在弱总修正区间（K*G/c及新配置对应量都很小）才能进一步写成：

    omega_eff^2 approximately K*G/(c*dt^2)
    c' approximately s^(2p-2)*(K'/K)*(tau/eta)^2*c

所以同一场景、同一时间目标，dt减半且迭代数翻倍，弱修正估算是compliance乘8，而不是乘2或4。若参数不变，恢复强度平方量约增8倍、特征频率约增sqrt(8)倍；不要把“刚度”“频率”“速度”都称作8倍。

完整非线性式虽然匹配孤立模型的等效恢复频率，仍不能消除不同dt的隐式Euler数值耗散/相位误差，更不能消除真实PBSTF多约束耦合。因此跨dt只可作调参种子，不宣称动态完全等效。

## 6. 粘性、扩散、摩擦与阻尼的频率

仅改变N、保持dt不变：XSPH、当前每子步浓度扩散、每步阻尼及壁摩擦系数保持不变。N变化可通过粒子位置和邻域间接改变效果，不能据此声称其直接调用次数增加。

若实际dt比eta，目标时间比tau，且几何相似：弱滤波近似epsilon'=epsilon*eta/tau；不包含N'/N。浓度若使用同类无量纲每步滤波也一样。每步速度保留系数的精确标量关系是q_damp'=q_damp^(eta/tau)；反之每步去除比例f'=1-(1-f)^(eta/tau)，后者只适用于接触集合/法线固定时的壁摩擦标量近似。

XSPH不是单一q：对固定邻域的一个特征模态，若衰减因子为1-epsilon*ell，则匹配需要epsilon'=[1-(1-epsilon*ell)^(eta/tau)]/ell。不同ell通常不能由一个epsilon'同时精确匹配，线性简式只在滤波足够弱时适用。

若未来将某一滤波从每子步一次改为每轮一次，那是算法调度变更；其总调用数才要另计，不能套用本表。

## 7. 多约束为何没有万能换算

真实PBSTF每轮同时累加密度、面积和部分距离约束。局部线性系统的残差映射是矩阵T，而不是单个q；保持总效果要求T_new^N'=T_old^N。各约束方向不正交、G分布不均、邻域与表面分类变化、接触截断等，都使几个全局compliance不足以满足该矩阵关系。孤立约束局部收敛也不保证耦合Jacobi收敛。

特别是面积约束目标为零面积，完整流体的非零体积来自密度与其他约束竞争；“单个面积约束残差保持一致”不等于“球的平衡形状与振荡保持一致”。

topology interval=2在5到20轮时导致循环内重建3到10次。把interval也乘4可粗略对齐迭代进度上的重建时刻，却会延长邻域陈旧区间，不能默认当作正确补偿。验证推导时先固定拓扑作单步对照；完整动态再保持合理重建频率并单独记录影响。

[XPBD原文](https://matthias-research.github.io/pages/publications/XPBD.pdf)讨论了传统PBD的迭代/时间依赖以及多约束下指数修正的局限。本文具体公式是从本地PBSTF分母与调度推导，不将其称为XPBD已有保证。

## 8. 建议的验证与本轮完成项

固定场景与dt，选N=5/10/20三档：记录密度/面积G/c分布、约束活跃次数与拓扑重建次数；先比较单步归一化位置修正，再检查方块体积、表面积下降曲线、振荡周期/衰减、内部密度分布、质心和动量。compliance按弱修正倍率只能作为初值，不能为追视频形状忽略体积或密度。

本轮计算核验了：5到20轮的残差补偿，距离/附着具体数值，以及s、dt、N同时变化时单约束等效频率的代数一致性（双精度误差量级1e-15以内）。未运行新仿真、未修改引擎或生产配方、未执行git mutation。已有阶段C进度保持不变。
