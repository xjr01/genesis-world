## 2. 代码中确认的成本来源

### 2.1 高频求解与拓扑

A每仿真步80轮密度+面积，40轮距离、40次拓扑重建。每次拓扑包含密度、照明屏幕、分类、法线/PCA、密度开关和局部网格等多个kernel，并在迭代中重排。

support=3ps的完整regular邻域有92个正权重邻居（静息晶格口径，动态可变）；旧PBD密度核只有6个。当前密度/法线/距离大量遍历支持域，面积则遍历已构建的一环网格，不能说每个面积操作都遍历92个邻居。

### 2.2 相同粒子位置重复做collider查询

`_separated_by_static_colliders`在多个邻居回调中调用；`static_collider_separates`对一对粒子的两个端点分别查询每个collider。位置在一轮Jacobi内不变时，同一粒子对不同邻居反复查询自己的SDF距离/法线。

建议优先评估“每粒子、每collider、每个位置版本”缓存距离/法线，在相同位置版本的邻居判断中复用。当前已有可变形collider缓存结构可作设计参考，但静态/kinematic的缓存必须在位置更新、重排和位姿改变后更新；不能拿旧轮缓存检查新位置，也不能复用于尚未查询的投影后候选位置。62k*3collider*距离加法线4个float约3MB，额外字段另计。边界包围盒粗筛也可先做，但不能漏掉真正接触。

不建议直接关闭隔墙过滤来换速度；4mm墙无跨壁对的结论依赖接触间隙，不能推广到瞬态穿入或其他资产。

### 2.3 逐拓扑重建的GPU到CPU同步

`_rebuild_topology`最后每次`qd_to_numpy(self._overflow)`，A为40次/仿真步，即每仿真秒9600次小读回。数据很小，但需要同步GPU，可能放大Python调度/启动间隙。

建议测量后设计GPU错误标志累积和安全门控、减少同步频率。必须保留溢出检查与及时失败语义，确保无效拓扑不会被消费；不能简单删掉检查，也不能每轮重置标志后在末步漏读早先溢出。

### 2.4 粘性为0仍计算；附着近零仍执行

- `_kernel_compute_viscosity`先遍历邻居算delta_vel，再乘系数。当前两个系数都是0，仍执行这次遍历。可增加零系数快路径，只跳过该邻居求和；仍要清空dpos，并保留后续摩擦、位置与碰撞处理。不能整个删除`_kernel_apply_viscosity`。
- `is_collider_adhesion_friction_enabled=True`使每轮都执行附着查询。1e12只让位置修正极小，并不会关闭查询成本。建议拆分附着和摩擦开关：摩擦仍开启、附着显式关闭。将极小有限修正改成零需回归，但符合当前“无附着、保摩擦”的设定目标。

### 2.5 诊断与录像成本

脚本每仿真步读取7组粒子状态，统计多项分位数/指标；额外读取collider位姿，并每步打印FPS。最新快测循环143.10ms与scene.step均值125.86ms之差约17.24ms/步，包含上述统计/位姿/日志等循环开销，不能全部归到某一次拷贝。

诊断阶段可关录像/非必要视觉更新、降低完整统计与日志频率；安全异常/穿隧监控仍保留或转GPU计数。正式录像按所需输出时刻更新画面；目前点渲染，没有运行表面重建，不能把慢归咎于recon。

## 3. 对当前D1方案的建议

当前D1只改变substeps/iters，其他配方不变，是“削减计算预算后还能否接受”的试验，不是保持相同物理响应的参数映射。

依照本项目迭代数推导，弱总修正模型里恢复强度与K/(c*h²)相关：A到B约降至1/4，A到C约降至1/8；这是模型估计，不是已测物理张力。若要做近似强度匹配对照，compliance候选相应为原值1/4与1/8，须先检查G/c和稳定性，不能直接替换正式参数。

子步减半还使每秒扩散和摩擦执行次数减半。固定几何、希望维持相同宏观时间响应时，弱滤波扩散.005可用.01作对照；固定接触法线/接触集合的标量摩擦近似为f'=1-(1-f)^2，即.1到.19。实际接触变化下须验证，不能保证逐帧等效。

建议把“原参数降预算”和“补偿参数的匹配对照”分别标注；优先一次改变一个变量。最新C静置失败已经说明不能只看速度。1粒失败的来源尚未定位，不擅自归因为穿墙、也不放宽零失败门槛。

PLAN/RECORD“摩擦只在t>=14s桌面阶段影响”需要勘误：材质开关全局生效，杯内壁接触从静置开始就受摩擦，可能影响起流/挂壁和快速档表现。

## 4. 推荐顺序与验证

1. 先等既有A测试完成；独占GPU测稳态短窗口，区分build/JIT、纯求解、拓扑、collider查询、快照统计、录像时间。性能测试记录完整有效配方及录像开关，输出唯一文件名，避免覆盖旧证据。
2. 优先零粘性快路径、附着/摩擦分离、诊断频率优化；逐项同初态短回归，不承诺未经测量的加速倍数。
3. 若profiling证实collider热点，做按位置版本的SDF查询复用；若同步热点明显，做保安全的错误标志批量检查。
4. 最后再调整子步/迭代、拓扑更新频率、SDF分辨率。前三者会改变数值结果，后者还影响薄壁几何精度；现有C档未过验收。

先用0.1–0.25s数值/性能短测筛掉明显失败者，再进入已有12s起流对照，最后40s出片。若必须覆盖新姿态，使用相应窗口，不把短静置通过当作倒奶通过。纯工程优化不改核、不改质量标定、不回退旧PBD。

按最新快测143.1ms/步线性外推，40s约22.9min（不含build及新增录像成本），仅是失败候选的成本量级，不是已达成的正式交付速度。
