# MF-18：向同事 PBSTF 对齐的修复方案

日期：2026-09-22。状态：代码审计与方案完成，尚未实施。根目录 `genesis-world/` 为只读对照；实现范围拟限定 `multiflow/`。本轮只修改文档，没有修改求解器、默认配方、旧视频或 settled 状态。

## 1. 结论与勘误

推荐完整迁移同事 PBSTF 的流体约束链，作为 multiflow 的独立流体求解路径，MF-18 验证通过后再切换。保留现有 PBD 供历史场景复现；不全局替换旧 PBD 的核。单独标定旧核可以做诊断，但不足以满足“尽可能与同事一致”。

需要修正前次报告的五处表述：

1. **不是改 Liquid.rho 一行就能校准。** `pbd_entity.py:649` 同时令 mass=rho、rho_rest=rho，密度比中相消。独立改质量或 rho_rest，又会改变旧梯度/epsilon/面积约束的相对响应，必须成套核对。
2. 同事质量标定使初始样本的**最大核密度**等于 rho0，适用于拥有完整邻域的均匀内部；不保证所有表面粒子的 C=0，也不能修复重叠初值。表面另外用 0.7rho0。
3. 同事并非所有场景都用 staggered：teapot/tap 明确用 regular，默认材质和 cube 用 staggered。`--scale` 控制 ps=2/scale；场景几何中的 /15 是另一件事。
4. 113 是连续体积估计。本轮枚举 regular 晶格，3ps 内严格正核权重的邻居为 **92 个（不含自身）**，旧 1.25ps 为 6 个。开销不能直接断言是 18 倍，须计入 hash cell、拓扑扫描和重建频率实测。
5. 旧 `.05/.09` 的“同事/MF-17 等效表面张力”结论撤回。按每秒投影次数 N/h 换算忽略位置回推速度及 h 的影响，不能确定物理张力；同事 compliance 也不是时间步无关的 XPBD 参数。这两个数只保留为旧 PBD 上已跑过的经验配方。

## 2. 数值复算与已有实验的证据边界

本轮用环境内 Python 对规则晶格做核求和（无仿真）：

- 旧 poly6、support=1.25ps、无自项：rho/rho_rest=0.4385705443，C=-0.5614294557。
- 只补自项、其他保持旧值：rho/rho_rest=2.0052520153，会从欠密变为过密；不能单独上线。
- 均匀压缩 regular 晶格至旧核 C=0：间距=0.001813439m，相对原始间距体积比=0.7454508。这是晶格分析，不是任意动态末态的体积定理。
- 同事 cubic、support=.006m、ps=.002m、完整 regular 邻域：sum W=125224338.17 m^-3；rho0=1000 时质量约 **7.985668e-6 kg/粒子**，接近 rho0*ps^3=8e-6。实际 build 仍按实际样本标定，不能硬编码该质量。

复核已有 `mf18_stcube_ston/stoff.log`：4s 时 on 的 span 约 (.0320,.0317,.0311)m、off 为 (.028,.028,.028)m；off 的 KE 约 2.8e-22，on 约 2.9e-8。这证明开关产生明显形变，不能据此认证物理张力数值。

旧报告“体积~0.69”来自均匀球假设下的半径估计，并非闭合表面体积；NN=.00175 推算密度也依赖均匀晶格假设。惯量三主轴相等不能区分立方体和球，按 r>0.9rmax 选外壳存在筛选偏差。旧记录另有 distance-off 的 1.497/1.484 与其他体积比口径矛盾，不能作严格“距离约束无影响”的证据。新验证应输出同口径的重建体积、面积和内部密度分位数。

## 4. 目标算法（先固定算法，再实现）

### 4.1 初始化

使用相同初始粒子坐标、sampler、rho0 和核；将 build 的质量暂设1，计算流体核密度最大值，再一次性赋 m=rho0/max_density。仅无墙、无重叠、内部邻域充分的参考场景用于首轮校准。禁止加载旧 PBD 压缩后的 settled 文件再将其当新参考密度。

MF-18真实尺度保持 ps=.002、support=.006、rho0=1000。regular 可与同事 teapot 对齐；另做 staggered/cube 交叉检查。密度自项只计一次。质量标定之后，所有质量、逆质量、默认质量、密度和 XSPH 权重统一口径。

### 4.2 每个子步

1. 重力/外部运动预测位置；重建邻域。
2. 按同事顺序重算密度、表面分类、m/rho 法线与 PCA、密度约束开关、局部网格。
3. 每轮对启用约束计算 C_i=rho_i/rho_target_i-1；rho_target 为内部1000、表面700。
4. lambda_i=-C_i / (c_density/m_default + sum_k |grad_k C_i|^2/m_k)。按每个约束的目标密度和梯度分配 delta x_k=lambda_i*grad_k C_i/m_k。表面和内部目标不同时，不能直接套旧的对称 `(lambda_i+lambda_j)/rho_i` 写法。
5. 累加同事面积约束；偶数轮累加表面/内部距离约束；统一 Jacobi 应用修正并执行边界投影。参考模式无旧 S_Corr、旧 epsilon、旧 density_relaxation 和负压 clamp。
6. 每2轮重建邻域及拓扑；速度由位置差分回推；末态重建邻域和密度后做同类型 m/rho 加权 XSPH。

面积、密度 compliance 保持同事代码的非时间归一化形式，不擅自改成 XPBD、不引入累计 lambda。后续物理张力标定是另一阶段。

## 5. 参数如何落地

**能直接定下的结构设置**：ps=.002、support/hash cell=.006、rho0=1000、自项开启、build质量校准、surface factor=.7、PCA开启、density mask阈值.8、S_Corr关闭、距离40/180且隔轮、拓扑间隔2。正式阶段全局 velocity_damping=1；保留杯壁无附着/无摩擦的用户选择。

**先做同输入参考对照，不声称时间等效**：在同事与迁移版本上指定完全相同 h、迭代数和参数。首轮取 MF-18 的 h=1/960、20轮；粘性=0、重力=0、无墙，便于分离压力和面积效果。参考 teapot 数值 c_density=33750、c_area=3/225 可用于这个代码一致性试验，但不是新生产推荐参数。

**空间缩放候选**：在局部构型、迭代数、时间步保持同口径，长度缩为 s 时，面积 compliance 按 s²、密度 compliance 按 s^-2 才维持相对投影强度。以 teapot ps=.006667→.002 的 s=.3 做局部几何候选，可得 c_area=.0012、c_density=375000，距离40/180保持。这只用于单步与小场景扫描；它不代表整个不同几何、不同时间配方的 teapot 被物理等效缩放，不能直接用于正式倒奶。

先检验密度响应，再以候选 c_area 的 .25/1/4 倍测试弱/中/强；固定其他参数。粘性独立从0起测，再测试同事 .05/.05 及 teapot .2/.05，不能将旧 PBF 的 .005 直接解释为同事 .005。h=1/480、1/960、1/1920 和10/20/40轮做敏感性验证后才选生产值；无需跑全部笛卡尔积。

## 6. 分阶段实施与验收

### A：参考与无墙流体核一致性

在 multiflow 新增独立 PBSTF 流体接入（material/entity/options/state/scene/simulator/vis），迁移密度、拓扑、面积、距离、XSPH 整条链。根目录同事当前另含吸水/可变形 collider/新 StateChange API 等依赖，不整库覆盖副本，也不直接复制一个 solver 文件就宣称可用；限定本阶段为纯液体最小依赖闭包。

验证：两份引擎用独立进程、明确打印 genesis.__file__，同初始粒子和参数，核对单步公开位置/速度；非对称小构型验证梯度有限差分；规则内部 rho/rho0 误差目标<1e-3；自项计数和质量比解析核对。表面天然欠密，不用全体粒子的 C≈0 作错误门槛。

### B：真实尺度无重力方块

复用现有3cm、3375粒方块，独立新输出目录。跑：① 面积关；② 面积开弱/中/强；③ 选定面积参数后再加入粘性。**面积开关不同时改变 .7 表面目标、分类和距离约束**，另设“全表面机制关”对照，避免混淆归因。双边密度与距离本身可能导致运动，不要求同事式面积关场景完全静止。

输出视频、位置快照、内部密度分位数、质心/动量/动能、表面有效网格比例和溢出、同一重建设置下的闭合表面积与体积。对初态和球参考独立核查重建偏差；比较重建体积与 sum(m)/rho0，并说明自由面/有限分辨率误差。球形度采用闭合表面面积-体积指标和全方向形状检查；禁止仅以三个主轴相等判成球。

候选验收目标：无 NaN/异常弹射；内部密度误差与重建体积误差分别控制在约2%/5%以内（先验证测量误差，超出如实失败而非调显示阈值）；面积开能持续降低表面积并趋圆，且不能靠大幅体积塌缩完成。这些是待验证目标，不是本轮已达成结果。完成视频交用户确认。

### C：杯壁与浓度适配

当前2ps厚墙约.004m，新support=.006m跨过墙厚。先测静态薄壁两侧水块与移动壁；密度、局部网格、距离、粘性、扩散逐项排查跨壁耦合。拓扑与颜色数据在排序后须保持粒子身份一致。

生产仍保留已要求的球墙/同源可见几何；密度边界权重需按新核单独配准，不再沿用“每个冻结球质量=液粒子质量”的假设。若改用同事 mesh collider 最接近原版，但会替换既有边界模型，需用户另行确认。参考 mesh 无墙/有墙对照与球墙工程扩展分开标注。

扩散保持现有守恒目的，重审核权重、单位和每秒扩散率，重新验证浓度守恒<1%。等质量检查 sum(c)，一般质量场检查 sum(m*c)。浓度不改变压力物性，除非另行请求。

验证原有穿隧、合法越唇、外壁驻留、运动位姿、浓度守恒指标；先静置再2s动态小测。重新生成 settled，记录 solver/核/ps/support/质量/配方/资产版本，拒绝静默加载旧 PBD 状态。

### D：MF-18 回归与参数定稿

保留真实几何、运动时间线和旧输出作为对照，先短片再40s正式视频。domain 建议单列变量：medium为[-.10,-.12,0]→[.34,.12,.30]，监测五侧近边界计数；扩大domain不能修复密度零点。重新测新cell下显存与帧时，旧cell下的哈希槽估计不再套用。

只有方块、薄壁/移动杯、浓度和完整倒奶均通过后才设置新默认。每阶段更新 PLAN/RECORD/STATUS，视频交用户验证；任何 git mutation 仍需明确许可。
