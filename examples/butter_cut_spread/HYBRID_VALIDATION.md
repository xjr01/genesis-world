# 双面黏附与薄层验证（2026-10-26）

此页保留首次双面黏附版本的数据。后续针对连续刀背薄层的完整对照，见
[沉积薄层验证](COHERENT_FILM_VALIDATION.md)。

此处的物理对照仍有效。之后发现并修正的刀面矩形与移动反光伪影，以及同一轨迹
的重新渲染验证，见 [薄层伪影修正](FILM_ARTIFACT_VALIDATION.md)。

本轮基准为提交 `21db304a6510bfd2173d35175a8a308f7f92eb6a` 的 standalone
firm-smooth 轨迹。新增双面接触、有限残留约束及粒子驱动薄层后，重新完成
8.4 秒、168,000 步、203 帧的切割—带起—转移—涂抹过程。

## 固定条件与结果

两边均使用 549,158 个黄油粒子、272,258 个面包粒子，黄油间距 0.6 mm，
时间步 50 微秒。黄油 G=80 kPa、K=150 kPa、屈服应力 600 Pa、稠度 25、
流动指数 0.5、密度 900 kg/m³，全程固定。两次运行的运动轨迹逐元素相同。

| 指标 | 原版 | 双面黏附版 |
| --- | ---: | ---: |
| 切片带起率 | 99.9517% | 99.9632% |
| 最终沉积率 | 80.9605% | 83.9407% |
| 最终涂抹跨度 | 76.537 mm | 78.726 mm |
| 切割时切片形变 RMS | 1.242 mm | 1.082 mm |
| 带起时切片形变 RMS | 1.860 mm | 1.554 mm |
| 原黄油块位移中位数 | 0.241 mm | 1.074 mm |
| 原黄油块位移 P99 | 1.054 mm | 2.625 mm |
| 面包粒子最大位移 | 13.459 mm | 20.186 mm |
| 抽样刀面穿越数 | 0 | 0 |

沉积中心偏移约 3.32 mm。面包同 ID 粒子位置差的 P99 为 0.802 mm，
中心位置差 0.160 mm，最高点比基准增加 0.410 mm。
最大面包位移增大来自局部横向滑移，因此不能声称所有局部运动不变。
调试时增加的“最大位移增量不超过 3 mm”检查未通过；调查后将宏观检查明确为
同 ID 位置差 P99、中心偏移、最高点抬升各不超过 1 mm，并继续记录最大位移。
这组指标用于区分局部滑动和整块面包被带起，不能代替视频检查。

`adhesion_compare` 对带起率、沉积率、跨度、形变、原黄油块位移、沉积中心、
面包位置及固定材质/轨迹的检查全部通过。全部粒子保持有限且激活，身份不变。
双面规则和局部厚度限制是本演示的接触近似，详见 [模型说明](HYBRID_ADHESION.md)。

## 残留与显示

原版确实存在刀面附近的残留；缺少薄层显示和不对称黏附共同影响了可见效果。
按同一体积分配规则统计有薄层贡献的真实粒子，负面/正面分别为：

| 时刻 | 原版 | 双面黏附版 |
| --- | ---: | ---: |
| 切割结束 | 42 / 30 | 38 / 51 |
| 带起 | 43 / 7 | 85 / 38 |
| 涂抹 | 1112 / 116 | 1389 / 441 |
| 最终 | 1 / 172 | 115 / 427 |

这些是薄层分配粒子数，不能等同于强制约束数。强制残留每面上限 128，
录制帧中同时约束峰值 118，静止体积 25.488 mm³，约为初始切片体积的 0.27%。
这不是每个积分步的峰值统计；两面约束上限合计 256 个，对应切片体积约 0.59%。
捕获、释放、冷却规则两面相同；没有额外生成粒子或留下永久涂色。

薄层外观沿用单独 cutting 的透明刀背薄层：颜色 `(0.96, 0.84, 0.56)`，
粗糙度 0.38，每粒子层光学深度 0.28；均匀一层对应不透明度约 24.4%，
相较本轮初版 0.45（约 36.2%）更淡、更透明。实体黄油外观不变。
实际透明度随真实覆盖厚度变化，并不是固定透明贴图。

薄层与三维重建使用互补的粒子体积分配；203 帧中最大相对体积分配误差
`2.22e-16`，二维积分体积最大误差 `2.65e-23 m³`。
最后一次外观调整只更新透明度及薄层颜色：三维表面、粒子与物理轨迹不变。
透明度解析更新与最后一帧从粒子重新计算的最大差为 `1.67e-16`。
