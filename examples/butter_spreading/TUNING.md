# 黄油数据集调参指南

## 配置、基准与复现

参数定义在 [config.py](config.py)。`--config` 接受部分 JSON，未填写的字段采用代码默认值；`--seed`、`--bread-particle-size` 和 `--butter-particle-size` 显式命令行参数优先。未知字段、非有限数字、负间距及超出本构定义域的参数会报错。修改实际参数后，应生成新的数据版本。

[configs/dataset.json](configs/dataset.json) 是用于批量生成的较低粒子数配置：面包间距 1.06666666666667 mm、黄油间距 0.6 mm、种子 17，共 310,755 粒子。省略配置和间距参数则使用 1 mm / 0.5 mm，共 428,160 粒子；这两个分辨率应分开统计。

```powershell
# 在本仓库根目录，使用已激活环境中的 Python。
$py = 'python'
& $py -m examples.butter_spreading.demo --config examples/butter_spreading/configs/dataset.json --save-trajectory --save-state --output-dir out/dataset/baseline-000

# 完成仿真、物理审计、黄油表面重建及波纹诊断。
& $py -m examples.butter_spreading.pipeline --config examples/butter_spreading/configs/dataset.json --output-dir out/dataset/baseline-pipeline-000
```

每个运行目录保存完整展开的 `run-config.json`。`completion.json` 表示仿真与所请求导出完成，包含配置哈希、关键源码哈希、库版本及命令；短测也会生成该文件。完整样本还必须有 `pipeline-completion.json`，其中 `is_complete`、`is_full_trajectory`、`is_accepted` 均为 true；并核对轨迹、配置和后处理产物的哈希。源码哈希覆盖入口、配置、轨迹、接触、材料和显示订阅模块；发布数据集时另存整个仓库提交、差异补丁和 `python -m pip freeze` 的环境记录。固定种子主要固定黄油初始抖动，GPU 并行归约仍可能出现微小浮点差异。

输出目录用于单次运行。入口拒绝覆盖已有运行，流水线要求空目录；失败样本保留原日志，重跑使用新的 `attempt` 目录。NPZ 中的初末位置和速度用于验收，恢复仿真还需要完整求解器状态和控制器时刻。

## 调整顺序

1. 先跑基准配置并冻结引擎、依赖、粒子间距、网格、时间步和相机。完整四秒覆盖下压、铺展和抬刀，1000 步只覆盖最初 0.035 秒。
2. 用相同种子，一次改变一个物理因素：先黄油屈服/流动性，再面包压实性，再黏附和剪切拖曳。对比全过程及最终铺展，避免不同初始采样掩盖参数影响。
3. 确认单因素趋势后测试组合的边界情况，例如高屈服黄油配硬面包、强刀面黏附配弱面包黏附。参数组合需要实际验收。
4. 用多个种子检查波动，再扩大采样范围。最后抽取代表性与最困难样本，将 `dt` 减半，并分别细化网格、粒子间距检查收敛。
5. 相机、颜色、灯光等外观随机化放在通过物理验收之后。保留同一物理轨迹对应的全部视角归属。

下列方向依据当前本构和接触公式；给出的试探值是小范围实验候选，并非已经验证的稳定区间。

## 黄油参数（JSON 的 `butter`）

| 参数 | 基准值 / 单位 | 调整作用与注意事项 |
| --- | --- | --- |
| `yield_stress` | 80 Pa | 增大后开始流动所需应力更高，通常更难铺开。第一轮可分别试 64、80、96。 |
| `consistency` | 25 Pa·s^n | 控制屈服后的速率阻力；增大通常更黏、更慢。可分别试 20、25、30。 |
| `flow_exponent` | 0.5 | 合法范围 0.25–1，影响剪切变稀程度；改变它也改变 consistency 的单位与速率意义。0.5 和 1 使用解析返回，其余指数使用迭代，耗时也可能改变。 |
| `shear_modulus` | 20000 Pa | 控制屈服前剪切刚度和弹性应力。增大应检查更小时间步。 |
| `bulk_modulus` | 150000 Pa | 控制体积压缩性。增大更接近体积保持，也会提高波速。 |
| `rho` | 900 kg/m³ | 同时改变惯性、重力与接触冲量对应的速度变化，应作为独立物理因素。 |

这是一套 Herschel–Bulkley 本构参数。当前实现没有温度状态及热传导；若数据集需要温度标签，应先标定温度到这些参数的映射。

## 面包参数（JSON 的 `bread`）

| 参数 | 基准值 / 单位 | 调整作用 |
| --- | --- | --- |
| `E` / `nu` | 16000 Pa / 0.15 | 弹性刚度与横向形变；较大 E 一般提高抗变形能力，接近 0.5 的 nu 会显著提高体积刚度。 |
| `rho` | 280 kg/m³ | 改变惯性、重量及单位体积质量。 |
| `compaction_yield_pressure` | 650 Pa | 孔隙开始永久压实的压力阈值；增大通常更难压出凹陷。可分别试 520、650、780。 |
| `compaction_hardening` | 5200 Pa | 随压实增加的阻力；增大可抑制继续塌陷。 |
| `densification_strain` | 0.32 | 进入更强致密化硬化的压缩阈值；增大将推迟该阶段。 |
| `densification_hardening` | 45000 Pa | 致密化阶段的二次硬化强度。 |
| `min_plastic_volume_ratio` | 0.35 | 塑性体积比下界；提高此值会限制永久压缩量。 |
| `shear_yield_stress` / `shear_hardening` | 700 / 7000 Pa | 控制永久剪切形变及其随压实增加的阻力。 |

面包形变直接保存在 `bread_particles` 中。评估压痕时同时看粒子压缩、表面凹陷和整体漂移。若下游自行绑定外观网格，还需验证其位移传递和网格雅可比。

## 接触参数（JSON 的 `contact`）

| 参数 | 基准值 / 单位 | 调整作用 |
| --- | --- | --- |
| `bread_stress` / `blade_stress` | 450 / 100 Pa | 面包/刀面的法向黏附强度。增大刀面黏附可能让更多黄油随刀抬起。 |
| `bread_shear_stress` / `blade_shear_stress` | 650 / 150 Pa | 切向拖曳应力上限。刀面可先试 120、150、180，观察推展与带走的平衡。 |
| `bread_slip_time` / `blade_slip_time` | 0.008 / 0.008 s | 相对切向速度松弛时间；更小代表更快拖曳，仍受剪切应力上限约束。 |
| `bread_contact_range` / `blade_contact_range` | 1.5 / 2.916666666666667 mm | 有限黏附作用距离。扩大距离会改变作用层和剥离行为，应与黏附强度分开调。 |
| `blade_normal_time` | 0.005 s | 刀面单侧法向响应的时间尺度；运行器使用 `dt / blade_normal_time`。减小会加强纠正。 |
| `blade_max_separation_speed` | 0.35 m/s | 法向纠正速度上限；过大可能产生尖峰或飞散，过小可能残留侵入。 |
| `blade_contact_margin` | 1.875 mm | 粒子中心相对刀面采用的接触裕量，会影响薄层和刀面附近的响应。 |
| `is_equilibrium_adhesion` | true | 使用有限分离层内的平衡黏附分布。关闭会改变接触定律，应单独标记数据版本。 |

所有距离在 JSON 中使用米，例如 1.5 mm 写作 `0.0015`。改变粒子间距时首先保持这些物理距离不变，再检查分辨率收敛。优先把 `blade_normal_time`、纠正速度上限和接触裕量作为数值接触控制量固定，先调材料与黏附。

## 刀具运动、几何和相机

`motion` 的位置均为世界坐标、单位米，Z 向上。`clearance` 字段实际存储刀具中心 Z，刀具底面还要减去半厚度 2.5 mm。面包参考上表面为 Z=26 mm。

| 字段 | 基准值 | 含义 |
| --- | ---: | --- |
| `press_end_x` / `spread_end_x` | -0.055 / 0.049 | 压入起点与铺展终点；固定时长下增大距离也提高水平速度。 |
| `start_clearance` / `press_clearance` | 0.0565 / 0.0445 | 初始高度与 0.9 s 压入结束高度。 |
| `sweep_clearance` / `sweep_end_clearance` | 0.0365 / 0.0348 | 加速结束高度与铺展结束高度。降低通常加深压入，应检查侵入、挤出及面包变形。 |
| `lift_clearance` | 0.0575 | 4 s 时抬刀结束高度。 |
| `y` | 0 | 运动轨迹的横向位置。 |

五段时间固定为 0–0.9、0.9–1.65、1.65–3.15、3.15–3.5、3.5–4 s。位置连续，速度按相邻时刻差分得到。刚体碰撞盒中心另加 `(2.1, 3.5)` mm 的 XY 偏移；导出的 `knife_positions` 使用工具参考位置。当前规定运动入口保持水平姿态。旋转/受力刀具使用接触模块的实际状态入口，并另行设计控制轨迹。

自定义 `motion` 可用于 `demo` 和 `pipeline`；审计从该次展开配置读取预期轨迹。沉积、铺展宽度和波纹测量区域仍针对当前面包与涂抹任务。改变动作目标或几何后，应同步修改 `audit.py` 的任务判据和 `ripples.py` 的测量区域，并给数据集建立新版本。

几何尺寸、初始黄油位置、MPM 域边界、相机位置/FOV/分辨率仍在 `demo.py:build_scene()` 中。扩大对象或更换运动范围时，同时检查粒子域、面包接触网格、相机覆盖和刚体碰撞条件。当前关闭刚体间碰撞的前提是只有支撑台与规定刀具、刀具始终高于台面；入口检查刀具底面。新增机械臂或其他刚体时应重新配置刚体求解。

## 数值精度与速度

| 字段 | 基准值 | 使用原则 |
| --- | ---: | --- |
| `dt` | 0.000035 s | 同步用于场景、MPM、黄油塑性返回、刀具速度和接触响应。减半可做时间收敛检查，完整步数约翻倍。 |
| `grid_density` | 512 m⁻¹ | 网格尺寸约 1.953125 mm。提高密度增加空间分辨率和计算/存储需求，也应重新检查稳定时间步。 |
| `bread_particle_size` | 0.00106666666666667 m | 基准面包 210,255 粒子。改动会改变离散质量、表面采样及接触网格。 |
| `butter_particle_size` | 0.0006 m | 基准黄油 100,500 粒子。增大节省计算，薄层与边缘的表达能力下降。 |
| `seed` | 17 | 控制规则黄油采样点上、每轴 ±0.45 个粒子间距的初始随机抖动。 |

提高刚度、降低密度、减小网格尺寸或提高运动速度后，需要复查时间步。弹性波速量级可用 `sqrt((K + 4G/3) / rho)` 理解，步长相对 `dx / c` 的比例可作为初始参考；非线性塑性和接触仍需完整实测。空间分辨率和时间步属于数值验证维度，通常不作为同一数据版本中未经标记的随机噪声。

评估速度使用 `timing.json` 的 `stepping_seconds` 和五段时间，单独统计初始化、导出、重建与渲染。比较时统一是否保存轨迹、是否开相机、依赖版本和缓存状态。首次编译与材料静态参数变化可能增加初始化；一个 GPU 上先串行运行，依据峰值显存及吞吐实测再决定并发。

## 一个可复用的批量生成示例

先把以下部分配置保存为 `examples/butter_spreading/configs/butter-yield-100.json`（目录位置可自选）：

```json
{
  "bread_particle_size": 0.00106666666666667,
  "butter_particle_size": 0.0006,
  "butter": {"yield_stress": 100.0}
}
```

```powershell
$py = 'python'
foreach ($sampleSeed in 17..21) {
    $sampleOutput = "out/dataset/yield-100/seed-$sampleSeed/attempt-01"
    & $py -m examples.butter_spreading.pipeline --config examples/butter_spreading/configs/butter-yield-100.json --seed $sampleSeed --output-dir $sampleOutput
    if ($LASTEXITCODE -ne 0) { throw "Sample failed: $sampleOutput" }
}
```

该示例会真实运行并审计每组参数，参数组合是否合格由输出决定。先对默认屈服应力重复相同种子，再做单因素比较。流水线限制 `0 < butter_particle_size <= bread_particle_size <= 0.002`，流水线会在启动前验证。当前 CLI 每次创建单场景，上面的批量生成按独立 episode 串行运行；按环境独立随机化参数的多环境入口需另行扩展。

生产批次为每个 episode 保存：唯一 ID、参数组、种子、展开配置与哈希、代码/环境版本、全部轨迹及时间戳、审计结果、各段耗时和失败原因。保持失败样本清单，避免静默丢弃造成参数分布偏差。按 episode 或参数组划分训练/验证/测试集；同一轨迹的相邻帧、多视角和外观变体放入同一划分。

## 样本入库验收与排错

| 观察或检查 | 建议处理 |
| --- | --- |
| 进程/流水线失败、缺少完成记录 | 保留日志，标记失败；检查 `full-pipeline-timing.json` 各阶段退出码。 |
| 时间覆盖不足、少于完整 97 帧、粒子数变化、NaN/Inf | 拒绝作为完整四秒样本。确认步数、离散参数和数值稳定性。 |
| 黄油几乎不铺开 | 先确认刀具确实接触，再分别试更低屈服应力、更低 consistency 或更强刀面切向拖曳。 |
| 抬刀带走过多黄油 | 分别检查刀面/面包的黏附强度、作用距离以及刀具抬起路径。 |
| 飞散、速度尖峰、刀面侵入 | 检查轨迹连续性、时间步、法向纠正时间/上限及裕量；先恢复基准并逐项重现。 |
| 面包凹陷不足或塌陷过深 | 分别检查压入高度、E、压实阈值及硬化；同时测量面包整体漂移。 |
| 表面颗粒感、锯齿或薄层丢失 | 先核对粒子与网格分辨率，再调重建参数。重建平滑无法替代稳定的粒子轨迹。 |
| 面包外观翻面/局部折叠 | 检查位移传递后的网格雅可比、法线和粒子变形；该几何检查应纳入最终渲染数据验收。 |

`physics-audit.json` 的检查包括：97 帧、有限状态、固定粒子数、时间有序、刀具轨迹、计算域、面包漂移小于 2 mm、无粒子飞散、最大连通分量占比大于 98%、沉积比例大于 75%、越出面包比例小于 1%、有效铺展宽度大于 60 mm、后段继续推进以及刀面侵入小于 0.1 mm。阈值针对当前几何和任务；自定义任务应建立有依据的标准。`pipeline` 完成这些粒子检查和黄油表面重建；波纹指标为诊断量，尚无统一合格阈值。`--record` 使用 Genesis 相机录像，视频质量及下游外观网格需另外检查。`is_accepted` 表示通过当前物理判据并完成后处理，并不自动保证所有下游任务的标签质量。

复现冻结的配置时，以相同初始粒子、刀具指令和采样时刻为前提，逐帧对比全部黄油/面包粒子、轮廓交并比和面包粒子位移。物理参数随机化样本会有意偏离基准，应通过任务质量和数值收敛验收；不要用“与默认轨迹逐粒子相等”筛掉合理多样性。
